ABOUT NAOREX.LINK

このサイトについて

naorex.link は、個人で開発した Web ツールと技術的な実験を公開するためのサイトです。

公開するもの

ブラウザ上で実際に操作できる独自の Web アプリを中心に、技術検証や学習の過程で作ったコンテンツを公開しています。 完成した機能だけでなく、特定の仕組みや考え方を試せる小さな実験も扱います。

公開中のアプリは、それぞれ独立したサブドメインで提供する場合があります。 現在の公開内容は、トップページのアプリ一覧から確認できます。

運営について

このサイトは、個人開発者の naorex が運営しています。 公開する情報は、アプリの目的や使い方、技術的な背景を理解するために必要な範囲に限ります。

  • 実際に動作を確認できるコンテンツを、分かりやすい説明とともに公開します。
  • 技術検証や学習目的であること、適用範囲や注意点を必要に応じて明記します。
  • 運営に不要な実名、住所などの個人情報は掲載しません。

ソースコードと連絡先

ソースコードや開発内容は、公開可能なものから GitHub プロフィール で案内します。当サイトへの問い合わせや連絡も、GitHub プロフィールに記載された連絡手段をご利用ください。
