# サイト全体のビジュアル統一

## 目的

ポータル、About、Blog案内、Privacy、2つのアプリ紹介ページでばらついていた見た目、書体、ヘッダー、フッター、導線を、アプリを見つけて使いやすい「静かな編集誌風」の世界観へ統一した。

## 実施内容

- `design.md` を追加し、Editorial／Gardenを基調とするデザイン方針、ページ種別、配色、書体、余白、操作状態、レスポンシブ方針を定義した。
- `tokens.css` を拡張し、Noto Serif JP／Noto Sans JP、紙面色、深緑のアクセント、文字サイズ、余白、罫線、角丸、モーション、レイヤーの共通トークンを整理した。
- `styles.css` に全ページ共通の編集誌風スタイルを追加し、中央ワードマークのN6ヘッダー、二重罫線、Ft1フッター、見出し階層、CTA、本文幅、フォーカス・ホバー・無効状態を統一した。
- 6つのHTMLページでGoogle Fonts、ナビゲーション順、フッター構造、ページ種別クラスを統一した。
- トップ、About、Privacy、Blogの長い見出しと、アプリガイドの索引を小画面向けに調整した。
- Hallmarkのpreflightとlogを今回のデザインシステムに合わせて更新した。
- READMEを確認し、`design.md` の役割と共通デザインシステムの運用ルールを追記した。

対象外として、外部サービス上のブログ本体と公開アプリ本体のUI、本文内容、URL、情報設計は変更していない。

## 検証

- 6ページすべてをHTMLとして解析し、重複ID、ローカルリンクとフラグメント、外部リンクの `noopener`、共通ナビゲーション順、フォント読込を確認した。
- Hallmark JSONの構文と、CSS変数65件の定義・50件の参照を確認し、未定義参照がないことを確認した。
- ローカルHTTP配信で6ページ、`styles.css`、`tokens.css`、WebP画像がすべてHTTP 200かつ正しいContent-Typeになることを確認した。
- Chromiumで6ページを320、375、414、768、1280、1920px幅で検証し、全36組み合わせで横スクロールがなく、ナビゲーション・CTA・フッターリンクが折り返さないことを確認した。
- 本文、補助文字、CTA、フォーカス色のコントラストを確認した。
- Hallmarkのpre-emit critiqueと58項目のslop testを実施し、全項目を通過した。
- `git diff --check` を実行し、空白エラーがないことを確認した。
